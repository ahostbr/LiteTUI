  • Boot-loads-nothing is itself a criterion (the 2026 OOM lesson: concurrent test boots each loading a model).

  8. POST /models/unload → status flips unloaded (VRAM freed by server's own accounting). 8b. Seat-guard cycle (Sentinel finding): re-load the model, then drive seat_guard.suspend/resume THROUGH the backend — suspended = not listed loaded, resumed = loaded at the recorded ctx (asked-vs-got compare), breadcrumb file created then cleared.   9. Kill spawned pid; assert process gone; log file non-empty (the instrument that writes the log demonstrably ran — instrument-trust audit).
